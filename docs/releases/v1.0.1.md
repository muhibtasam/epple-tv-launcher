Smoother, lighter and more reliable. Install over 1.0.0; your settings and data are kept.

## Improvements
- **Smoother, lighter Home screen.** Epple TV redraws far less while the Home screen is idle.
- **Calmer wallpaper motion.** The slow wallpaper zoom pauses while you use the remote and stops after 3 minutes without input.
- **More efficient screensaver.** Home wallpaper motion and artwork rotation pause while the screensaver is showing.

## Bug fixes
- **Search:** the hint and the "No results" message now appear only when they should.
- **Notifications:** app icons in Control Center display correctly, and a notification you open is cleared from Epple TV and from the app that posted it.
- **Update notification:** stays until the new version is running, and stays if you cancel or the installation fails.
- **Storage:** downloaded update files are removed once they are no longer needed.

## Install or update
- **Updating from 1.0.0:** download `epple-tv-1.0.1.apk` and install it over the existing app. Don't uninstall first.
- **New install:** see [Installation](https://github.com/muhibtasam/epple-tv-launcher#installation).
